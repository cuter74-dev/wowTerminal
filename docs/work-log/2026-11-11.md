## #180 — 탭에 AI 에이전트 작업 표시 (GitLab #79)

- 사용자 요청: "ai가 일하는지 탭에 표시 … orca처럼". 결정은 프로그램+출력으로 판단하는 것(추천안)이다. Orca처럼 에이전트에 hook을 설치하지 않는다.
- Orca 확인: 에이전트별 hook을 설치하고 제목에 표식을 그린다. 사용자는 tmux 안에서 Claude Code를 쓰는데, tmux가 제목·OSC 9;4를 바깥으로 넘기지 않는다. 사용자 데몬이 옛 프로토콜 1이라 탭의 전면 프로세스도 알 수 없다. 그래서 화면 문구로 판정한다.
- 실측(가상 터미널 pyte, 짧은 질문 한 번씩):
  - Claude Code 2.1.322: `· Meandering…`, `✳ Wrangling… (2s · ↓ 229 tokens · thinking with xhigh effort)`. 끝나면 `✻ Baked for 1s · done 3:44 PM`. **"esc to interrupt"는 더 이상 나오지 않는다.** 바이너리의 회전 글리프는 ·✢✳✶✻✽ 또는 *.
  - Codex 0.167: `• Working (2s • esc to interrupt)`.
  - Gemini CLI는 설치돼 있지 않아 문서상 `(esc to cancel, 3s)`.
- 어떻게:
  - `src/aiActivity.ts`의 두 패턴(Claude 상태 줄 모양, "esc to interrupt)"·"(esc to cancel, Ns)"로 끝나는 줄)으로 판정한다. 출력 뒤 300ms에 보이는 화면 전체를 본다.
  - 끝남은 1.5초 동안 계속 없을 때만 알린다.
  - App이 탭에 회전하는 ✻(움직임 줄이기 설정이면 멈춤)를 띄우고, 앞에 없는 탭에서 끝나면 알림 점과 데스크톱 알림(11개 언어)을 낸다.
- 시험: `src/aiActivity.test.tsx` 15건(실측 줄 그대로, 평범한 글·완료 줄은 아님, 도구 호출 사이 잠깐 사라짐은 끝남 아님). 스캔 연결을 끊거나 1.5초 유예를 없애면 실패한다.
- **사고**: Codex 화면 실측 때 시작 화면이 업데이트 메뉴("1. Update now")였다. 입력한 글자의 "1"이 그걸 골라, 사용자 Codex CLI가 0.149.1 → 0.167.1로 업데이트됐다(OpenAI 공식 설치 스크립트, 15:47). 옛 버전은 남아 있다. 이후 실측 스크립트는 시작 화면에 번호 메뉴·질문이 있으면 입력하지 않는다. 되돌릴지는 사용자에게 묻는다.

## #181 — 하단 AI 사용량 표시(Claude·OpenAI Codex·Gemini) (GitLab #80)

- 사용자 요청: "하단에 사용량을 표시 … claude, openai, gemini … orca처럼". 결정: 로그인된 것만 자동 표시하고 설정에서 끌 수 있게(추천안).
- Orca 확인(app.asar):
  - Claude는 `api.anthropic.com/api/oauth/usage`(헤더 `anthropic-beta: oauth-2025-04-20`)의 five_hour·seven_day.
  - Codex는 `chatgpt.com/backend-api/wham/usage`의 rate_limit.primary/secondary_window.
  - Gemini는 `cloudcode-pa` loadCodeAssist → retrieveUserQuota buckets.
- 어떻게:
  - `src-tauri/src/ai/usage.rs`가 로그인 정보를 읽는다. Claude는 macOS 키체인(`security`로 묻지 않고 읽힘) 또는 `~/.claude/.credentials.json`, Codex는 `$CODEX_HOME|~/.codex/auth.json`, Gemini는 `~/.gemini/oauth_creds.json`.
  - 그 회사 주소에만 묻는다. 만료(Claude expiresAt, Codex JWT exp, Gemini expiry_date)거나 401이면 "expired"이고, 다른 앱 토큰은 갱신하지 않는다. 오류 문구에 토큰은 없다(HTTP 코드·network만).
  - `UsageBar`(하단 22px 줄)는 5분마다, 창 포커스 때(1분 간격), 클릭 때 새로 고친다. 마우스를 올리면 요금제·초기화 시각이 나온다. 85% 이상은 빨강, 60% 이상은 노랑.
  - 설정 → 일반 → "AI 사용량 표시"(기본 켜짐, 11개 언어). 모바일·분리 창에서는 숨긴다. PRIVACY.md에 절을 추가했다.
- 실측(2026-11-11, 상태·%만 출력): Claude max 주간 29%(5시간 창 null), Codex plus 5시간 0%·주간 1%. Gemini는 이 기기에 로그인이 없어 실측하지 못했다(Orca 구현대로 작성, 해석은 시험).
- 시험: Rust `ai::usage` 5건(RFC3339, 실측 응답 모양, Gemini buckets, JWT exp)과 `live_usage`(ignored, 실제 호출). 프런트 `src/usageBar.test.tsx` 3건. 전체 vitest 88건, cargo 89건, 빌드·clippy 통과.
