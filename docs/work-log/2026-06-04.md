## #55 — 긴 명령 완료 알림 + 탭 배지

### 무엇을 / 왜 / 어떻게
- 백엔드: tauri-plugin-notification 추가(Cargo + lib.rs init + capability notification:default), npm @tauri-apps/plugin-notification.
- 버스: commandBus.ts(emitCommandDone/onCommandDone). Terminal OSC 133 D에서 emitCommandDone({paneId,durationMs,exit}).
- App: 구독 → durationMs>=8000 && 백그라운드(탭≠활성 || !document.hasFocus())면 setTabAlerts + sendNotification(title=탭 라벨, body=✓/✗ + 시간). 권한 요청. 활성 탭 되면 배지 해제(effect).
- TabBar: alertedTabIds로 주황 점 배지. tabsRef/activeTabIdRef로 최신값 참조(리스너 1회 등록).
- 임계값 8초. 보고 있는 탭이면 알림 안 함.

## #59 — 입력 브로드캐스트

### 무엇을 / 왜 / 어떻게
- terminalRegistry: broadcastEnabled 플래그 + setBroadcastEnabled/isBroadcastEnabled + broadcastInput(origin, text)(origin 제외 모든 등록 터미널에 sendInput → PTY 직접 쓰기라 onData 재진입 없음=루프 없음).
- Terminal: onData·IME 미러에서 입력을 broadcastInput(paneId, data). 대상 패널은 셸 에코로 표시.
- App: broadcast state → useEffect로 setBroadcastEnabled 동기화. TitleBar에 broadcast/onToggleBroadcast 전달.
- TitleBar: 📡 토글 버튼(켜짐=빨강 강조). broadcast 라벨 11개 언어.
