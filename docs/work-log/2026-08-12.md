## #148 — 기본 다운로드 폴더 설정

**무엇**: 다운로드할 때마다 폴더 선택 다이얼로그가 떠서 매번 대상 폴더를 골라야 했다. 설정에 "기본 다운로드 폴더"를 추가하고, 다운로드는 묻지 않고 그 폴더로 바로 저장. 특별히 다른 곳에 받고 싶을 때만 새 컨텍스트 메뉴 "폴더 지정 다운로드…"로 고른다.

**어떻게**:
- `settings.ts`: `general.downloadDir` 추가(기본 `""` = OS 다운로드 폴더).
- `SettingsModal.tsx`: 일반 탭에 입력란 + 폴더 선택 버튼(로그 폴더 패턴 재사용). 11개 언어 라벨.
- `FileBrowser.tsx`:
  - `resolveDownloadDir()`: 설정값 우선, 비우면 `@tauri-apps/api/path`의 `downloadDir()`. `~`/`~/…`는 `homeDir()`로 확장(Rust `sftp_download`는 경로를 그대로 쓰므로 프론트에서 해소).
  - `doDownload(entry, askDir)`: 기본은 다이얼로그 없이 **현재 로컬 패널 폴더**로 저장(사용자 피드백 — 패널이 기본 다운로드 폴더에서 시작하므로 안 움직이면 기본 폴더, 이동했으면 그 위치; 이름 충돌 해소 #137은 대상 폴더 기준으로 그대로 동작). `askDir=true`(컨텍스트 메뉴 "폴더 지정 다운로드…")면 종전처럼 폴더 선택.
  - 폴백: OS 다운로드 폴더를 못 얻는 환경(모바일 등)은 로컬 패널 cwd → 그것도 없으면 폴더 선택.
  - 패널 간 드래그 다운로드는 종전대로 보이는 로컬 패널 cwd에 저장(드롭 대상이 명시적이므로).
  - 로컬 패널 시작 위치도 기본 다운로드 폴더(사용자 추가 요청). 경로 오류 시 홈으로 폴백.
