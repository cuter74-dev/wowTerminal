### 어떻게

1. **붙여넣기** (`Terminal.tsx` `doPaste`): `sendToSessionRef`(PTY 직접 쓰기) →
   `termRef.current.paste(txt)`. xterm의 paste 경로라 bracketed-paste 래핑과 `\n→\r` 정규화가
   적용된다. ⌘V/Ctrl+V는 원래 이 경로였고 컨텍스트 메뉴만 빠져 있었다.
2. **OSC 8** (`Terminal.tsx` XTerm `linkHandler`): `http:`/`https:`/`mailto:`만 opener로 열고
   (opener 기본 스코프와 동일) 나머지는 무시. `activate(event, text, range)`의 `text`는 표시
   텍스트가 아니라 **대상 URI**라서, 표시 텍스트는 `range`로 버퍼에서 읽어 비교한다. 스킴·끝
   슬래시를 뺀 값이 다르면(`[문서](https://evil…)` 류) 플러그인 dialog `confirm`으로 실제 주소를
   보여주고 확인받는다. 문구는 STR에 11개 언어로 추가(`linkMismatch`). 판정 함수는 node로
   javascript:/file:/data:/커스텀 스킴 차단, 대소문자 스킴 허용, 불일치 텍스트 판정 확인.
3. **bash OSC 133** (`pty/manager.rs`): 원인은 `__wt_precmd`가 preexec 가드(`__wt_pe`)를
   **PROMPT_COMMAND 도중에** 0으로 리셋한 것. 뒤이어 사용자 훅이 실행될 때 DEBUG trap이 C를
   보냈다(실행 시간에 프롬프트 대기 시간이 섞이고 장시간 명령 알림이 오발). 리셋을
   PROMPT_COMMAND 맨 끝의 `__wt_arm`으로 옮기고, 가드를 1로 시작해 첫 프롬프트 전 C도 없앴다.
   rc 본문을 `BASH_RC` 상수로 빼고, 실제 bash를 `PROMPT_COMMAND='true user_hook'`과 함께 띄워
   마커·프롬프트 순서를 검사하는 테스트 추가. **옛 rc로 돌리면 실패함을 확인**
   (`["C","D;0","C","P",…]` vs 기대 `["D;0","P","C",…]`).
