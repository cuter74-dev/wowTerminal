# 2026-11-16 작업 기록

## #193 — 앱 재시작 뒤 에이전트 상태, 알림 언어 (GitLab #92)

**무엇:** 0.22.1을 쓰는 중 들어온 제보 두 가지("로컬 탭에서 작업 중 표시가 안 뜬다", "작업이 끝나도 알림이 안 온다")를 살펴보다 찾은 문제 세 가지를 고쳤다.
- 알림과 첫 탭 이름이 설정 언어를 따른다. 지금까지는 언어와 상관없이 늘 영어였다("AI finished — waiting for you", "Local shell 1").
- 앱을 다시 켠 뒤(업데이트 재시작 등) 데몬 세션에 다시 붙으면, 실행 중인 프로그램이 화면 전체를 다시 그리게 한다. 그래서 재시작 전부터 돌던 Claude Code도 탭 표시(✻ / ?)와 에이전트 목록에 잡힌다.
- 다시 붙을 때 다시 그리는 옛 출력은 아무 일도 다시 일으키지 않는다. 옛 클립보드 복사(OSC 52), 옛 알림·벨(OSC 9/777/99, BEL), 옛 터미널 질의에 대한 답(OSC 7501), 옛 "일하는 중 → 끝남" 상태 보고(켜자마자 "끝남" 알림)가 해당한다.

**왜:**
- 알림 언어: App은 언어 문맥(LangProvider)을 자기가 그리므로, App 안의 `useT`는 늘 기본값(영어)을 읽었다.
- 재시작 뒤 표시: 다시 붙으면 데몬에 남은 최근 출력 512KiB만 다시 그린다. Claude Code는 바뀐 칸만 고쳐 그려서, 그 512KiB에 입력 상자가 없는 경우가 많다. 그러면 화면 판정이 아무것도 못 찾는다. 0.22.1 전에 켠 Claude Code는 상태 신호(OSC 7501)도 보내지 않아 다른 방법이 없다. 실제 데몬에 남은 출력으로 화면을 다시 만들어 보니 두 탭에서 입력 상자가 빠져 있었다.
- 옛 출력의 부작용: #174는 xterm이 자동으로 보내는 답만 막았다. 7501 질의에 대한 답은 따로 보내고 있어 막히지 않았고, 클립보드·알림·상태 보고는 처음부터 막는 장치가 없었다.
- 알림이 화면에 안 뜬 제보는 앱 문제가 아니었다. macOS 알림 기록에는 앱이 보낸 "끝남" 알림이 다 남아 있었고, 그 맥에서 wowTerminal의 "알림 허용"이 꺼져 있었다. 같은 코드의 시험용 앱은 허용돼 있어 모두 화면에 떴다.

**어떻게:**
- `src/i18n.tsx`에 `pickT(dict, lang)`를 더하고, App은 설정 언어로 직접 문구를 고른다(설정 state를 App 맨 앞으로 옮김).
- `src/components/Terminal.tsx`
  - 재생이 끝나면 높이를 한 줄 줄였다가 150ms 뒤 되돌린다. 크기 바뀜 신호가 두 번 가야 프로그램이 크기 변화를 본다(한 번으로 합쳐지면 Node는 크기가 그대로라 다시 그리지 않는다).
  - pty에서 실제 Claude Code 2.1.325로 확인했다. 이 신호를 받으면 화면을 지우고 입력 상자까지 전부 다시 그린다. 신호가 없으면 아무것도 다시 그리지 않는다. 프롬프트에 있는 zsh는 프롬프트만 제자리에 다시 그린다.
  - 숨은 탭(크기 0)은 건드리지 않는다. 보일 때 실제 크기로 바뀌면서 어차피 다시 그린다.
  - 재생 중(`replaying > 0`)에는 7501 질의에 답하지 않고, 클립보드에 쓰지 않고, 알림·벨·명령 끝남을 내지 않는다. 에이전트 상태는 다 읽은 뒤 마지막 것 하나만 알린다.
- 테스트: `src/appLanguage.test.tsx`는 App 전체를 띄워 한국어 설정일 때 첫 탭 이름과 "끝남" 알림 문구를 본다. `src/replayQueries.test.tsx`는 7501 질의 무응답, 상태 보고 마지막 것만, 알림·벨·클립보드 무시, 보이는 패널의 높이 조정, 숨은 패널 제외를 본다(5개 추가). 새 시험은 고치기 전 코드에서 모두 실패한다. 전체 JS 179개가 통과했다.
- 남은 일: 격리 시험용 앱으로 "Claude Code가 도는 중에 앱 재시작 → 탭 표시" 실제 확인(사용자가 자리를 비울 때).

## #194 — 배포 도구와 스토어 문구를 저장소에 (GitLab #93)

**무엇:** 모바일 배포 도구와 스토어 "새 기능" 문구를 저장소로 옮겼다. 버전별 스토어 문구는 `docs/store-notes.md`에 둔다. 채널별 배포 절차와 도구는 기존 App Store 배포 문서처럼 비공개 미러에 둔다.

**왜:** 사용자 지시(11-16) — 새 기능·기획·문구·배포 링크·결정은 그 프로젝트 문서와 AppFlowy에 남기고, 원본을 임시 폴더에만 두지 않는다. 이 도구들은 macOS가 주기적으로 지우는 세션 임시 폴더에만 있었고, 한 번은 사라져 대화 기록에서 다시 만들었다.

**어떻게:** 도구는 자격 증명을 배포하는 맥에서만 읽는다(저장소에 비밀 값·개인 경로 없음). 처음에는 공개 저장소에도 올렸다가, 배포 절차 문서는 비공개 전용으로 두어 온 관행에 맞춰 공개 쪽에서는 빼고 스토어 문구만 남겼다. 옮긴 도구로 심사 상태 조회와 0.22.2 서명 검증을 다시 돌려 확인했다.
