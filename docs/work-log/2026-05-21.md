### Why
- wowTerminal is a desktop terminal differentiated by "AI integration + rich SSH management."
  - **AI**: the user should be able to freely choose not only external cloud APIs but also local Ollama/llama.cpp and self-hosted OpenAI-compatible servers. If the backend abstraction isn't nailed as the first step, adapters proliferate later.
  - **SSH**: to end the "where's my key file again?" workflow once and for all, host profiles + keys should live in a secure store (OS keyring / passphrase encryption) and connect with one click from the UI.
- Why Tauri: ~1/15 the bundle size of Electron and lower memory; a Rust backend lets us unify PTY/SSH/AI clients in one language.

### Notes / Troubleshooting
- A fine-grained PAT cannot have its scope raised via `gh auth refresh -s ...`. You must edit the token's permissions directly on the GitHub web. (Classic PATs can.)
- Passing an unsupported flag like `--rc` to the `create-tauri-app` CLI gets interpreted as a directory name, creating a `--rc/` folder. You must move the result to the root and fix `productName`/`name`/the lib call in `main.rs`.
