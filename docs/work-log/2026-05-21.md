- `npm install`, `cargo check` 모두 무에러로 통과.

### 왜
- wowTerminal은 "AI 통합 + 풍부한 SSH 관리"가 차별점인 데스크탑 터미널이다.
  - **AI**: 외부 클라우드 API뿐 아니라 로컬 Ollama/llama.cpp, 자체 호스팅 OpenAI 호환 서버까지 사용자가 자유롭게 선택할 수 있어야 한다. 백엔드 추상화를 첫 단추로 정확히 잡지 않으면 나중에 어댑터 난립.
  - **SSH**: "키 파일 어디 있더라"를 매번 찾는 워크플로를 한 번에 끝내려면 호스트 프로필 + 키를 안전한 저장소(OS 키링/패스프레이즈 암호화)에 두고, UI에서 원클릭 접속해야 한다.
- Tauri 선택 이유: Electron 대비 번들 사이즈(약 1/15) 및 메모리 절감, Rust 백엔드라 PTY/SSH/AI 클라이언트 모두 한 언어로 통합 가능.

3. **Tauri 스캐폴딩**

5. **설계 문서**

6. **검증**
   - `npm install`: 72 packages, vulnerability 0건.
   - `cargo check`: 의존성 컴파일 포함 무에러 (42초).

### 메모 / 트러블슈팅
- Fine-grained PAT은 `gh auth refresh -s ...`로 scope 상승이 불가능. GitHub 웹에서 토큰 권한을 직접 편집해야 함. (Classic PAT은 가능)
- `create-tauri-app` CLI에 `--rc` 같은 미지원 플래그를 넘기면 디렉토리 이름으로 해석돼서 `--rc/` 폴더가 생긴다. 결과물을 루트로 이동 후 `productName`/`name`/`main.rs`의 lib 호출까지 손봐야 함.
