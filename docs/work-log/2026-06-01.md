# 2026-06-01 작업 로그

## #33 — 창 간 탭 재결합(드래그-병합) + 탭을 창 밖으로 드래그해 새 창

메인/보조 창 개념 없이, 어떤 창이든 다른 창으로 끌어다 놓으면 합쳐지고, 탭을 창 밖으로 끌어내면 그 위치에 새 창이 뜨도록.

### 무엇을 / 왜 / 어떻게
- **드래그-병합**(WKWebView는 창 간 DnD 불가 → OS 창 이동 감지 방식):
  - 모든 창이 `getCurrentWindow().onMoved`로 자기 이동을 감지 → 타이틀바 지점을 글로벌 이벤트 `wt://winpos`로 방송.
  - 각 창은 그 지점이 자기 영역 안이면 드롭 오버레이(`MergeDropOverlay`) 표시.
  - 이동이 멈추면(300ms 디바운스=release) `getAllWebviewWindows`로 대상 창을 찾아 `mark_session_detached`(백엔드 detach_guard)로 세션 보호 후 `wt://merge`{targetLabel,...} 전송 → 대상 창이 그 세션을 attach하는 탭 추가, 소스 창은 탭/창 닫기. 메인/분리 구분 없이 대칭.
- **탭을 창 밖으로 드래그 → 새 창**: 탭 pointer 드래그 시 커서가 창 경계 밖(또는 탭바 아래)으로 나가 떼면 분리. `open_detached_window`에 위치 x,y 추가 → 떼는 화면 좌표에 새 창 생성.
- **버그 수정**: 분리(attach 모드) 창은 spawn하지 않아 `onSession`을 호출 안 해 `sessionByLeaf`가 비었음 → 병합 시 세션을 못 찾고 새 셸을 띄워 내용이 사라짐. attach 모드에서도 `onSession(attachSessionId)`를 호출해 세션을 보고하도록 수정(연쇄 분리/병합에서 세션·스크롤백 유지).
- 백엔드: `mark_session_detached(sessionId, kind)` 명령(open_detached_window와 동일 detach_guard). capability에 `core:window:allow-close`/`allow-set-focus`, `core:event:allow-emit`/`allow-listen` 추가.

### 한계
- WKWebView가 창 밖 마우스 이벤트를 끝까지 전달하는지에 따라 "완전히 밖에서 떼기"가 안 될 수 있음(경계/탭바 아래 폴백 유지). 병합은 의도적 제스처(다른 창 위로 끌어다 놓기)에 맞지만 창을 단순히 겹쳐 놓을 때도 발동 가능.

## #34 — 한글 IME 쌍자음 깨짐 + SSH 접속 시 프롬프트 잔상

### 무엇을 / 왜 / 어떻게
- **한글 IME 쌍자음(있/았/껐/짰)**: 진단 로그로 근본 원인 확인 — `ㅆ`(=Shift+ㅅ) 입력 시 들어오는 **Shift keydown**이 IME 핸들러에서 "비-문자·비-백스페이스 키"로 분류돼 `resetIme()`를 호출, 조합 중인 글자와 미러 상태(imeSent)·textarea를 비워버림. 그 결과 `ㅆ`이 단독 자모로 새고(`이ㅆ`) 미러가 실제 내용과 어긋나 삭제도 안 됨.
  - 수정: 조합 중 **수정자 단독 키(Shift/Control/Alt/Meta/CapsLock)는 reset 없이 통과**시켜 미러 세션 유지(`customKeyEventHandler`의 `imeActive` 블록).
- **SSH 접속 시 프롬프트 잔상**: OSC 7 cwd 훅을 런타임 주입할 때 readline이 명령(약 240자)을 그대로 에코하며 줄바꿈→화면 스크롤. 기존 절대 커서 저장/복원(ESC7 프론트 저장 + ESC8 복원)이 스크롤로 무효화돼 위쪽에 프롬프트 잔상이 남음(창 높이 의존). `stty -echo`는 셸 readline 자체 에코라 효과 없음.
  - 수정: 주입 시점 **프롬프트 폭(`term.buffer.active.cursorX`)과 명령 길이로 에코 줄바꿈 줄 수 N을 계산**(자릿수 수렴 루프), 셋업 끝 `printf '\033[NA\r\033[J'`가 **상대 이동으로 정확히 N줄 위로 올라가 에코를 지움**. 상대 이동이라 스크롤이 나도 정확하고 배너는 보존.
- 진단용 console.log(IME keydown/mirror/onData, SSH 원시 바이트) 전부 제거.

### 검증
- 재빌드 후 새 SSH 탭 접속 → 프롬프트 단일·배너 보존·잔상 없음, 있/쌍자음/대문자 정상 입력·삭제 확인.

## #35 — 대체 화면(alt-screen) 휠 스크롤

### 무엇을 / 왜 / 어떻게
- 배경: 사용자가 원격에서 스크롤이 안 된다고 보고 → 진단 결과 원격이 **tmux**(초록 상태줄) 안에서 실행 중이었음. tmux는 대체 화면을 써서 출력이 에뮬레이터 스크롤백에 안 쌓이므로 휠 무동작(tmux는 `set -g mouse on` 필요). 같은 원리로 less/man/git log/vim 등 대체 화면 앱도 기본 휠 스크롤이 안 됨.
- 추가: **대체 화면 + 앱이 마우스 리포팅 미사용**일 때 휠 deltaY를 위/아래 화살표(앱 커서 키 모드 반영: `\x1bOA/B` vs `\x1b[A/B`)로 변환해 PTY로 전송 → less/man/vim 등에서 휠 스크롤. `term.attachCustomWheelEventHandler`로 구현, `term.buffer.active.type`/`term.modes.mouseTrackingMode`로 분기.
  - 줄 수는 `deltaY / 셀높이(container.clientHeight/rows)`로 환산(트랙패드 픽셀/휠 모두 자연스럽게), 최소 1줄·최대 rows.
  - 마우스 모드를 켠 앱(tmux mouse on 등)·일반 화면은 그대로 둬(return true) 기존 동작 유지.
- 설정 토글 `terminal.altScreenWheelScroll`(기본 on) 추가 — settings.ts 타입/기본값, SettingsModal 11개 언어 라벨 + 체크박스.

## #36 — 터미널 선택 텍스트 복사(⌘C/Edit 메뉴/ tmux) — **완료**

> 복사 동작 확정(사용자 테스트 완료). 진단 console.log 전부 제거 후 커밋.

### 증상
- 터미널에서 글자를 드래그 선택 후 복사가 안 됨. 특히 **tmux 안에서** 복사 불가.

### 원인 분석 (단계적)
1. xterm.js의 선택은 DOM 선택(`document.getSelection`)이 아니라 **자체 선택 모델** → macOS 기본 복사(⌘C/Edit 메뉴)가 빈 내용을 복사.
2. **tmux 밖에서는 복사가 됨**을 확인 → 즉 아래 프론트 수정 자체는 동작하고 `navigator.clipboard`도 정상.
3. **tmux 안에서만 실패**하는 진짜 원인: 앞서 스크롤용으로 켠 tmux `set -g mouse on` 때문에 **드래그가 tmux로 가서** xterm 로컬 선택이 안 만들어짐(선택이 없으니 ⌘C가 복사할 게 없음). `Shift+드래그`로 우회도 이 환경에선 안 됨(드래그 자체가 안 됨 — xterm shift-bypass 미동작 추정).

### 한 작업 (src/components/Terminal.tsx)
- **⌘C 키 핸들러**: `customKeyEventHandler`에서 `metaKey+c`(선택 있을 때) 가로채 `term.getSelection()`을 `navigator.clipboard.writeText`로 복사. 선택 없으면 통과(Ctrl+C SIGINT 보존).
- **copy 이벤트 리스너**(컨테이너 스코프): Edit 메뉴/우클릭 Copy 대응 — `clipboardData.setData(text/plain, 선택)` + `preventDefault`.
- **OSC 52 핸들러**: `registerOscHandler(52, …)` — `\e]52;c;<base64>` 수신 시 base64 디코드해 시스템 클립보드에 write. **읽기 요청("?")은 무시**(원격이 클립보드 못 읽게). tmux(set-clipboard on)/vim 등이 복사 시 이 시퀀스를 보내면 시스템 클립보드 반영.
- 디버깅용 진단 console.log는 동작 확정 후 전부 제거.

### tmux 쪽 설정(원격 ~/.tmux.conf, 사용자 적용함, tmux 3.4)
```
set -g set-clipboard on
set -ga terminal-overrides ',*:Ms=\E]52;%p1%s;%p2%s\007'
```
→ tmux copy(드래그/copy-mode)가 OSC 52로 시스템 클립보드에 넣도록. (현재 OSC 52 수신 로그 확인 대기 중.)

### 결과 / 검증
- tmux 밖: 드래그 선택 → ⌘C 정상 복사.
- tmux 안: `set -g set-clipboard on` + `set -ga terminal-overrides ',*:Ms=\E]52;%p1%s;%p2%s\007'`(tmux 3.4) 적용 후 드래그/copy-mode 복사 → OSC 52로 시스템 클립보드 반영. 사용자 테스트 완료.

### 후속 메모
- xterm shift-bypass(마우스 모드에서 Shift+드래그 로컬 선택)는 이 환경에서 동작 안 함 → tmux는 OSC 52 경로가 정석. 필요 시 별도 이슈로 검토.
