### 막힌 것: Apple 계약 만료로 macOS·iOS 전부 불가

데스크탑 릴리스는 **초안으로 남겨 뒀다**(publish 안 함). macOS 잡 2개가 실패해 에셋이
11개(정상 17개), `latest.json`이 7개 플랫폼(정상 11개)이고 `darwin-*`가 전부 없다.
이 상태로 publish하면 **macOS 사용자의 자동 업데이트가 깨진다**(업데이터가 자기 플랫폼을
찾지 못하고 내려받을 Mac 빌드도 없다). `finalize-windows-updater`도 mac 실패로 skip됐다.

원인은 하나다:

```
publish-tauri (macos-latest, *-apple-darwin):
  failed to notarize app: Error: HTTP status code: 403.
  A required agreement is missing or has expired.

App Store Connect API (/v1/apps):
  403 FORBIDDEN.REQUIRED_AGREEMENTS_MISSING_OR_EXPIRED
```

공증(notarytool)과 ASC API가 같은 계약 검사를 거치므로 **macOS 공증과 iOS 업로드가 함께
막힌다**. ASC JWT 인증 자체는 통과했으니 자격증명 문제가 아니다. Account Holder 계정으로
App Store Connect → 비즈니스/계약에서 대기 중인 계약(보통 Apple Developer Program License
Agreement 갱신)에 동의해야 풀린다.

동의 후 할 일: `gh run rerun 39525556548 --failed` → 에셋 17개·`latest.json` 11개 플랫폼
재검증 → `gh release edit v0.20.17 --draft=false --latest` → iOS 1.0.14 TestFlight 업로드·심사 제출.

**교훈**: `gh run watch --exit-status`가 **종료코드 0을 반환했지만 macOS 잡 2개는 실패**였다
(워크플로 전체 결론이 success로 잡혔다). 앞으로도 publish 전에 **에셋 개수와 `latest.json`
플랫폼 수를 직접 세는** 검증을 건너뛰지 말 것.

### 작업 환경 메모

시놀로지가 꺼져 있어 저장소의 dataless 파일(`.git` 2,540개 포함)을 읽을 수 없어, 릴리스
전체를 `/private/tmp`의 GitHub 클론에서 진행했다. 시놀로지를 켜면 작업트리는
`git fetch origin && git reset --hard origin/main`으로 맞추면 된다.

Android 빌드에서 두 번 걸렸다.
1. `rustup`이 PATH에 없어 `tauri`가 Android 타깃 설치를 시도하다 중단 — Homebrew `cargo`가
   먼저 잡혀 있었고 타깃은 `~/.cargo/bin` rustup 툴체인에 있었다. `PATH`에 `~/.cargo/bin`을
   앞세워 해결.
2. `app/build.gradle.kts`의 `file(storeFile)`이 **app 모듈 디렉터리 기준**으로 풀려
   `app/wowterminal-upload.jks`를 찾았다. `keystore.properties`의 `storeFile`을
   `~/.android-keys/wowterminal/` **절대경로**로 바꿔 해결(키 파일을 저장소 트리에 두지 않는
   쪽이 안전하다).
