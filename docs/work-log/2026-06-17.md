# 2026-06-17 작업 로그

## #103 (GitHub) / #22 (GitLab) — AI 어시스턴트에 현재 시스템 정보 자동 주입 (1차/2)

### 무엇을 / 왜
- 사용자가 AI에 질문할 때, 모델이 지금 **어떤 시스템이 열려 있는지**(로컬 셸 vs 어느 SSH 호스트, OS/셸/유저/cwd)를 몰라 명령 제안이 부정확했다.
- 사용자 요청: "LLM이 명령어를 날려서 알 수 있게 할 수 있지 않아?" → 안전한 **자동 컨텍스트 주입(①)** 을 1차로, **승인형 도구 루프(②)** 를 2차로 단계 적용하기로 함.
- 1차는 LLM이 명령을 *고르지 않고*, 우리가 고정된 읽기 전용 정보만 채워준다 (②와의 안전 경계).

### 어떻게
**백엔드 (Rust)**
- `ssh/session.rs`: 기존 `exec_capture`(별도 채널, 대화형 화면에 흔적 없음)를 재사용한 `probe_system()` 추가. 고정 프로브 `SYSTEM_PROBE_SCRIPT` = `uname -srm` + `$SHELL`/`whoami` + `/etc/os-release`의 `PRETTY_NAME`.
- `ssh/manager.rs`: `probe_system(id)` 래퍼.
- `ssh/commands.rs`: `ssh_probe_system` Tauri 명령.
- `pty/commands.rs`: `local_system_info` — 같은 머신이라 서브프로세스 없이 std(unix는 `uname`으로 커널 보강). 셸/유저/OS·arch.
- `lib.rs`: 두 명령 invoke_handler 등록.

**프론트엔드 (TS)**
- `AIPanel.tsx`: `getSessionId` prop 추가, 세션별 `sysInfoCache`(시스템 정보는 안정적이라 1회만 조회). `probeSystemInfo()`가 SSH=`ssh_probe_system`/로컬=`local_system_info` 호출. `sendText`의 컨텍스트 블록에서 `system: … ; cwd: …` 영어 한 줄 system 메시지를 맨 앞에 주입(답변 언어는 기존 로컬라이즈 메시지가 결정 → 영향 없음).
- `App.tsx`: `getSessionId={(pid) => sessionByLeaf.current[pid]}` 전달.

### 검증
- `cargo check` 통과(exit 0), `tsc --noEmit` 통과(exit 0).
- 릴리스 전: 서명 로컬 빌드로 로컬 탭 + SSH 호스트 각각에서 AI가 연결 시스템을 정확히 반영하는지, 대화형 터미널에 추가 출력이 없는지 + 한글/영어 입력 정상 확인 예정.

### 추가 보강 (테스트 피드백 반영)
- **시스템 한 줄을 출력-첨부 토글에서 분리** — 토글이 꺼져 있어도 "어떤 시스템인지"는 항상 전송(첫 테스트에서 토글 OFF라 generic 답변이 나온 문제). 토글은 100줄 스크롤백 첨부만 제어.
- **컨텍스트 줄 수 옵션화 → 설정으로 이동** — 사용자 요청대로 토글 옆 인라인 입력이 아니라 **설정 → 일반 → "AI 컨텍스트 줄 수"** 에서 변경(기본 100, 1~2000). `AppSettings.general.aiContextLines` 추가(영속은 기존 설정 저장 경로), `App`이 `AIPanel`에 `contextLines` prop 전달 → `getRecentText(contextLines)`. 라벨/힌트 i18n 11개 로케일.

### 테스트 피드백 2차
- **설정 줄 수 입력이 지우면 100으로 튐** — 빈 값일 때 즉시 폴백하던 것을, 타이핑 중엔 문자열 상태(`aiLinesStr`)로 빈 값/중간값을 허용하고 **blur 때만** 1~2000으로 보정하도록 변경.

## #104 (GitHub) / #23 (GitLab) — 모달이 입력 드래그 선택을 밖에서 떼면 닫히는 버그

### 무엇을 / 왜
- 호스트 등록 폼·설정 등 오버레이 클릭으로 닫히는 모달에서, 입력칸 텍스트를 드래그 선택하다 패널 밖에서 손을 떼면 `click`이 오버레이에서 발생해 창이 닫히고 입력이 사라짐(테스트 중 발견).

### 어떻게
- 오버레이에 `onMouseDown`으로 `target===currentTarget`(=오버레이에서 누름 시작) 플래그 기록 → `onClick`에서 그 플래그 + `target===currentTarget`일 때만 닫음. `HostForm.tsx`, `SettingsModal.tsx`에 적용. (다른 오버레이 모달들도 같은 패턴이지만 보고된 두 곳 우선 적용.)

### 다음 (2차, 별도 이슈 예정)
- 승인형 도구 사용 루프: LLM이 실행할 명령 제안 → 매 명령 사용자 승인 → 실행 → 결과 되먹임 반복. 백엔드 tool-use 루프 신설.
