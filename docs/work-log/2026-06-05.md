## #80 — 로컬 셸 PATH 누락 (비로그인 셸이 ~/.zprofile 스킵)

### 무엇을 / 왜 / 어떻게
- 증상: 사용자 화면에 .zshrc:116/130 command not found: pyenv/jenv + 명령이 안 먹음. v0.10.0.
- 원인: pty/manager.rs가 셸을 비로그인으로 spawn. macOS Terminal.app은 로그인 셸 → /etc/zprofile(path_helper)·~/.zprofile 읽음. Homebrew 공식 설치가 brew shellenv를 ~/.zprofile에 넣으므로 비로그인은 Homebrew/그로 깐 도구 PATH가 통째로 빠짐 → command not found.
- 검증: `/bin/zsh -c 'echo $PATH'`(비로그인) vs `/bin/zsh -l -c ...`(로그인) — 로그인만 /etc/zprofile path_helper 반영. /etc/zprofile에 path_helper 확인.
- 수정: zsh `cmd.arg("-l")`. 기존에 만들던 임시 .zprofile(사용자 .zprofile source)이 비로그인이라 dead였는데 -l로 실제 로드됨. bash는 로그인이면 --rcfile 무시되므로 비로그인 유지하되 rcfile에서 /etc/profile + ~/.bash_profile/.bash_login/.profile를 source해 PATH 확보.
