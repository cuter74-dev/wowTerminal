## #127 — 인라인 자동완성 수락 키를 →/End에서 Tab으로

### What / Why
- #102에서 도입한 인라인 히스토리 제안의 수락 키가 →(오른쪽 화살표)/End였는데, **순수 커서 이동과 충돌**했다. 줄 끝에서 커서를 움직이려 해도 제안이 들어와 버리고, tmux/TUI 안에서는 애초에 동작하지 않았다.
- fish·zsh-autosuggestions 관습(→)보다 이 앱에서는 Tab이 덜 충돌한다고 판단 — 제안이 떠 있을 때만 Tab이 수락을 가로채고, 없으면 평소대로 셸 완성으로 통과시키면 두 기능이 공존한다.

### How
- `src/components/Terminal.tsx`: →/End 가로채기 블록을 통째로 제거해 **순수 커서 이동으로 복귀**.
- Tab 핸들러에 수락 분기 추가 — `!e.shiftKey && suggestionRef.current && term.buffer.active.type !== "alternate"`일 때 제안의 미입력분(`slice(lineBufRef.current.length)`)만 세션에 write하고 제안을 비운다.
- 제안이 없거나 대체 화면(vim/tmux/less 등)이면 그대로 `\t`를 흘려보내 셸 자동완성이 동작한다. Shift+Tab은 종전대로 역탭 `\e[Z`.
- 제안은 커서가 줄 끝일 때만 존재한다는 기존 불변식(화살표 이동 시 onData가 라인 추적을 리셋)을 그대로 활용 — "제안이 있다 == 줄 끝"이라 별도 커서 위치 계산이 필요 없다.
