## #39 — 새 탭 접속 시 다른 세션 출력이 새어 상단에 엉뚱한 프롬프트가 찍힘

### 무엇을 / 왜 / 어떻게
- 증상: 호스트 목록에서 새 탭으로 SSH 접속하면 상단에 다른 서버/세션의 프롬프트가 찍히고 그 뒤로 새 서버 배너가 이어짐(예: mscllm 새 탭에 `cuter74@testllm:~$`가 보임). 그동안 추적하던 "상단 프롬프트 잔상"의 진짜 근본 원인.
- 원인: `ssh:output`/`pty:output`은 **모든 세션 공유 전역 이벤트**. `Terminal`의 출력 리스너 필터가 `if (sessionId && payload.session_id !== sessionId) return`이라, 새 탭 spawn이 끝나기 전(`sessionId === null`)엔 조건이 false가 되어 **다른 활성 세션의 출력까지 이 터미널에 써졌음**. 마침 다른 탭에서 Claude Code가 활발히 출력 중이라 그 프롬프트가 새 탭 상단에 샜다.
- 수정: 필터를 `if (!sessionId || payload.session_id !== sessionId) return`로 변경 — sessionId 설정 전엔 아무것도 쓰지 않음. `sessionId = await invoke(spawnCmd...)`는 await 직후 동기 할당이라(이벤트 콜백은 이후 태스크에서 처리) 자기 세션의 배너/출력 유실은 없음.

### 메모
- 이전에 "상단 프롬프트"를 OSC 7 주입 탓으로 보고 주입을 제거(#37)했는데, 그건 곁가지였고 실제 근본 원인은 이 전역 출력 필터 버그였다. (OSC 7 주입 제거 자체는 별개로 유지 — cwd 동기화는 ~/.bashrc 훅으로 안내.)

## #40 — tmux 재접속 시 화면이 아주 좁은 폭으로 깨짐 (숨김 탭 0크기 fit)

### 무엇을 / 왜 / 어떻게
- 증상: 여러 testllm 탭이 같은 원격 tmux 세션에 attach된 상태에서 tmux 내용(Claude Code)이 ~10칸 폭으로 줄바꿈돼 세로로 깨져 보임.
- 원인: 배경(숨김) 탭은 display:none → 컨테이너 0 크기. 그때 `ResizeObserver`가 `fit()` 호출 → cols/rows가 최소값(~2)으로 줄어 원격 PTY로 전달. tmux는 attach된 클라이언트 중 **가장 작은 크기**에 맞추므로, 한 숨김 탭의 tiny 크기가 공유 세션 전체를 쪼그라뜨림.
- 수정: `safeFit()` 도입 — 컨테이너 `clientWidth/Height >= 8`일 때만 fit. 적용 지점: 초기 fit, ResizeObserver, finishAttach(이후 resize도 가드), 설정 변경 effect, 등록된 `fit()` 메서드.
- 보완(원격 권장): tmux `set -g window-size latest`로 가장 작은 게 아닌 최근 활성 클라이언트에 맞추게.

### 현재 깨진 세션 복구
- 남는 testllm 탭을 닫아 클라이언트를 줄이거나, 각 탭을 한 번씩 포커스해 재fit, 또는 tmux에서 `tmux resize-window -A`.

## #42 — 터미널 Tab 키가 AI 패널로 포커스를 넘김

### 무엇을 / 왜 / 어떻게
- 증상: 터미널에서 Tab을 누르면 가끔 포커스가 AI 어시스턴트 영역으로 이동.
- 원인: 인라인 자동완성 제안이 떠 있을 때의 Tab 분기가 `return false`만 하고 `e.preventDefault()`를 안 호출 → xterm은 처리 안 하지만 브라우저 기본 Tab(포커스 traversal)이 그대로 실행돼 다음 포커스 대상(AI 패널 textarea)으로 넘어감. 제안 없을 땐 xterm이 처리하며 preventDefault해서 안 샜기에 "가끔"으로 보였음.
- 수정: `customKeyEventHandler`에서 Tab(metaKey/ctrlKey/altKey 없음)을 포괄 처리 — 항상 `e.preventDefault()`. 제안 있으면 수락, 없으면 셸로 `\t`(Shift+Tab은 역탭 `\x1b[Z`) 전달 후 return false. 포커스 이동 원천 차단.
