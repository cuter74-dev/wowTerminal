# 2026-11-14 작업 기록

## #188 — 켜 둔 채로 업데이트 확인 (GitLab #87)

**무엇:** 데스크톱 앱이 켜 둔 동안에도 새 버전을 찾고, 눈에 띄게 알린다.
- 확인 시점: 켤 때, 켜 둔 동안 4시간마다, 절전에서 깨어났을 때(마지막 확인 뒤 4시간이 지났으면), 창이 다시 앞에 올 때(밀린 확인만).
- 새 버전이 있으면 탭 줄 아래 안내 줄: "새 버전 wowTerminal X이 나왔습니다" + 재시작해도 이어지는 것(macOS·Linux: 터미널·SSH 세션) 또는 닫히는 것(Windows) + [재시작해서 업데이트] [나중에]. 앱이 뒤에 있으면 버전마다 데스크톱 알림 한 번. 저절로 재시작하지 않는다.
- "나중에"는 그 버전의 안내 줄만 숨긴다. 서버 목록의 "↑ 버전" 버튼은 남고, 더 새 버전이 나오면 안내 줄이 다시 뜬다.
- 함께: Claude Code 폴더 신뢰 확인(번호 없는 `❯` 메뉴 + `Enter to confirm · Esc to cancel`)도 에이전트 목록에서 "답을 기다림"으로 잡는다(#187 후속, 0.22.0 홍보 캡처 중 발견).

**왜:** 사용자 지시(11-14 텔레그램) — 껐다 켜야 업데이트를 알 수 있었다. 전에는 서버 목록이 뜰 때 한 번만 확인했고, 표시도 서버 목록 아래 작은 버튼뿐이라 왼쪽 패널이 파일·에이전트이거나 접혀 있으면 보이지 않았다.

**어떻게:**
- `src/updates.ts`: 확인·설치 상태를 모듈 하나로 모았다(`useSyncExternalStore`). App이 데스크톱 메인 창에서만 `startUpdateChecks()`를 부른다. 5분마다 벽시계를 봐서 4시간이 지났으면 확인한다 — 절전 중엔 타이머가 멈추므로 깨어난 뒤 첫 틱에서 밀린 확인을 한다.
- 설치는 전과 같은 순서: 저장 안 한 파일 확인 → 받기·설치 → 앱 종료 표시(#153, 데몬 세션을 죽이지 않게) → 재시작.
- `src/components/UpdateBanner.tsx`: 안내 줄과 데스크톱 알림. 새 문구 11개 언어.
- HostList는 자체 확인을 없애고 공용 상태의 "↑ 버전" 버튼만 그린다.
- 지표 영향: latest.json 다운로드 수가 "실행 수"만이 아니게 된다(켜 둔 앱이 4시간마다 더함). 총괄에 알렸고 주간 지표 설명에 반영됐다.
- 테스트: `src/updates.test.tsx`(확인 시점·설치 순서·실패·안내 줄 표시/숨김 12개), `src/agentScan.test.ts`(신뢰 창 기준 화면 + 입력란 오탐 방지).
