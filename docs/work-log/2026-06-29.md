## #121 — SSH 첫 접속 호스트 키 다이얼로그 Enter 수락

### What / Why
- 비밀번호 로그인 흐름에서 "첫 접속 — 호스트 키 확인" 창을 마우스로만 수락할 수 있었음. 키보드만으로 진행되게.

### How
- `src/components/FirstContactModal.tsx`: window keydown으로 **Enter = 신뢰·접속**, **Esc = 취소**(busy 중 무시). 포커스 무관 동작.

## #122 — 인라인 자동완성: 내장 플래그 사전

### What / Why
- 자동완성이 히스토리 + 시드 몇 개로만 제안됐음. 자주 쓰는 명령의 플래그/서브명령을 → 로 완성하고 싶음. (실시간 `--help` 파싱은 무겁고 보안 이슈라 내장 사전 방식 선택)

### How
- `src/commandHistory.ts`: `COMMAND_FLAGS` 사전(git/docker/claude/kubectl/npm/systemctl/ssh/apt/cargo) + `suggestFromFlags()` — 마지막 토큰을 사전으로 완성(prefix 보존). `suggest()`는 히스토리 매칭 없을 때 사전으로 폴백. 9케이스 로직 검증.
- 표시는 터미널 우하단 `→ {suggestion}` 박스(기존), 수락은 →/End.

## #123 — LLM 백엔드 사고력(reasoning) 강도

### What / Why
- LLM 등록 시 사고력 옵션을 넣고 싶음. LLM마다 옵션이 다르지만(OpenAI=reasoning_effort, Claude=thinking, Gemini=thinkingBudget), 앱은 **OpenAI 호환만** 지원하므로 `reasoning_effort`(low/medium/high) 하나로 통일.

### How
- `ai/config.rs`: `OpenAiCompatibleConfig.reasoning_effort: Option<String>`(serde default).
- `ai/adapters/openai_compat.rs`: 어댑터 필드 + `with_reasoning_effort()` 빌더 + `OpenAiChatRequest.reasoning_effort`(skip_serializing_if None) 주입.
- `ai/commands.rs`: SaveBackendArgs/BackendInfo + reasoning_effort, register 시 빌더 체이닝.
- `src/types.ts` BackendInfo + reasoningEffort, `LlmSetupModal.tsx`: 드롭다운(없음/low/medium/high) + 저장/복제/로드. 라벨은 별도 미니 사전(en/ko).
- cargo check + tsc 통과.
