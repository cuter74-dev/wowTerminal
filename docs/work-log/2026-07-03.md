## #124 · #125 · #126 — 탭바 오버플로 / 방향키 탭 이동 / SSH 재접속 화면 정리

### #124 탭바 오버플로 (bug)
- 탭 많으면 오른쪽 끝 너머 탭 접근 불가(minWidth 120 고정 + macOS 오버레이 스크롤바 숨김).
- `TabBar.tsx`: 탭 축소(minWidth 88 + `flex:0 1 auto`), 세로 휠→가로 스크롤(**rAF 관성 보간**), 활성 탭 `scrollIntoView`, 컨테이너 `userSelect/WebkitUserSelect:none`(WKWebView는 Webkit 접두사 필수)로 스크롤 중 라벨 선택 방지, + 버튼 flexShrink 0.

### #125 방향키 탭 이동 (added)
- 탭 클릭 후 ←/→로 전환. roving `tabIndex`(active=0) + onKeyDown. 클릭/화살표 시 탭에 포커스.
- **핵심**: `App.tsx`의 탭 전환 자동 터미널 포커스 useEffect가 키 네비를 뺏던 문제 → `onActivateByKey`로 `tabKeyNavRef` 세팅 시 그 rAF의 터미널 focus를 1회 스킵 → 포커스가 탭바에 유지되어 연속 화살표 가능.

### #126 SSH 재접속 잔상 (bug)
- `Terminal.tsx` `spawnFresh`가 버퍼를 안 지워 일반 SSH 재접속 시 잔상 위에 겹침(tmux는 attach가 다시 그려 OK).
- 모드 해제 write 다음 `term.clear()` 추가.
