## #112 (GitHub) / #31 (GitLab) — 단어 삭제(Option/Alt+Backspace) · 줄 삭제(Cmd+Backspace)

### 무엇을 / 왜
- 표준 readline 삭제 단축키 요청: Option+Delete=단어 삭제, Cmd+Delete=줄 전체 삭제.

### 어떻게 (`Terminal.tsx` 커스텀 키 핸들러)
- `Alt+Backspace`(Option+Delete) → `\x1b\x7f`(ESC+DEL) 전송 → zsh/bash backward-kill-word. 전 플랫폼.
- `Meta+Backspace`(Cmd+Delete) → `\x15`(Ctrl-U) 전송 → 줄 시작까지 삭제.
- 둘 다 preventDefault + return false로 xterm 기본 전송 중복 방지. 단축키 문서 갱신.

### 검증
- `tsc` 통과. 서명 빌드로 Option/Cmd+Delete 동작 확인 예정.

## #114 (GitHub) — 모바일 2단계: 터치 UI (온스크린 키바 + 슬라이드오버 패널)

### 무엇을 / 왜
- iPad/Android는 물리 키보드·마우스가 없고 화면이 좁다. 1단계(컴파일·실행)에 이어 2단계로 터치 UX를 만든다.
- (1) 셸에서 필수인 Esc/Ctrl/Tab/방향키/제어문자/기호를 탭으로 보낼 온스크린 키바.
- (2) 호스트 목록·AI 패널을 좁은 고정 컬럼 대신 평소엔 숨기고 버튼으로 여는 슬라이드오버 시트.

### 어떻게
- `src/mobileInput.ts`(신규): `mobileCtrl` 스티키 모디파이어(켜면 다음 글자 1개를 Ctrl 조합으로 전송 후 자동 해제) + `ctrlSeq()`(영문자→제어문자 변환). `Terminal.tsx`의 `attachCustomKeyEventHandler` 상단에서 플래그 확인해 소프트키보드 입력을 가로채 제어문자로 전송.
- `src/components/MobileKeyBar.tsx`(신규): 하단 가로 스크롤 키바. Ctrl 토글 + Esc/Tab/방향키/⌃C·D·Z·R·L/`|~/-:` 등 기호/Home·End·PgUp·PgDn. 활성 SSH 탭일 때만 표시.
- `src/components/MobileSheet.tsx`(신규): 좌/우 슬라이드오버 시트(backdrop 탭으로 닫힘). 레이아웃 행에 position:relative 기준으로 absolute 오버레이.
- `src/App.tsx`: 모바일 전용 상단 툴바(☰ Hosts / ✨ AI 토글, `mobilePanel` 상태로 한 번에 하나만). 호스트 목록·AI 패널 JSX를 `hostListEl`/`aiPanelsEl`로 추출해 데스크탑 고정 컬럼과 모바일 시트가 공유. 데스크탑 컬럼/PanelEdge는 `!isMobile` 게이트. 모바일에서 호스트 탭 시 새 SSH 탭 열고 시트 닫음.

### 검증
- `tsc --noEmit` 통과, `vite build` 성공.
- iPad Pro 11" 시뮬레이터 실기동 시각 검증: 상단 툴바, 좌측 호스트 시트, 우측 AI 시트, 하단 키바 모두 정상 렌더 확인(시드 호스트 주입 + 임시 시드 탭으로 활성 탭 상태 재현).
- **검증 중 진짜 버그 발견·수정**: `main`이 `height:100vh`라 iOS 가시 뷰포트보다 약간 커서 하단 키바가 화면 밖으로 잘렸음 → `100dvh`(동적 뷰포트 높이)로 변경(데스크탑 무영향). 시각 검증이 아니었으면 못 잡았을 표시 버그.
