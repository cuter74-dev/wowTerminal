## #112 (GitHub) / #31 (GitLab) — 단어 삭제(Option/Alt+Backspace) · 줄 삭제(Cmd+Backspace)

### 무엇을 / 왜
- 표준 readline 삭제 단축키 요청: Option+Delete=단어 삭제, Cmd+Delete=줄 전체 삭제.

### 어떻게 (`Terminal.tsx` 커스텀 키 핸들러)
- `Alt+Backspace`(Option+Delete) → `\x1b\x7f`(ESC+DEL) 전송 → zsh/bash backward-kill-word. 전 플랫폼.
- `Meta+Backspace`(Cmd+Delete) → `\x15`(Ctrl-U) 전송 → 줄 시작까지 삭제.
- 둘 다 preventDefault + return false로 xterm 기본 전송 중복 방지. 단축키 문서 갱신.

### 검증
- `tsc` 통과. 서명 빌드로 Option/Cmd+Delete 동작 확인 예정.
