## #135 — 폴더 재귀 전송 + 다중 선택

### What / Why
- 파일 하나씩만 전송 가능했다. 폴더는 ← / → 버튼·컨텍스트 메뉴·드래그 어디서도 거부됐고, 여러 파일을 옮기려면 한 번에 하나씩 반복해야 했다.

### How — 백엔드(`src-tauri/src/ssh/sftp.rs`)
- `download`/`upload`가 먼저 `metadata`로 **디렉토리 여부를 판정**하고, 디렉토리면 재귀 경로를 탄다.
- 재귀 다운로드: 스택으로 원격 트리를 훑어 **(파일 목록, 총 바이트)를 먼저 수집**하고 로컬 디렉토리를 만든 뒤 순차 스트리밍. `.`/`..`은 건너뛴다.
- 단일 파일 스트리밍을 `stream_download`(64KB 청크)로 분리하고 `base`/`total`을 받게 해, **진행률을 (앞선 파일 누계 + 현재 파일 진행) / 전체**로 보고 → 폴더 전체가 **하나의 transfer id**로 표시된다. 업로드도 대칭 구조.
- **커맨드 인터페이스는 그대로** — 목적지에 basename을 join하면 자연스럽게 대상 디렉토리가 되므로 프론트/시그니처 변경이 없다.

### How — 프론트(`src/components/FileBrowser.tsx`)
- 다중 선택: **Cmd/Ctrl+클릭 토글**, **Shift+클릭은 앵커부터 범위 선택**. 패널 헤더에 선택 개수 배지.
- ← / → 버튼과 컨텍스트 메뉴가 **선택 전체**를 전송. 다운로드는 대상 폴더를 **한 번만** 고르고 전부 그 안에 저장.
- 폴더를 화살표·컨텍스트 메뉴·패널 간 드래그 **모든 경로에서 허용**으로 변경.

## #134 — 이름 변경 / 새 폴더 / 새 파일이 얼어붙던 문제

### What / Why
- 세 동작이 브라우저 `prompt()`를 쓰고 있었는데, **Tauri의 WKWebView에서 `prompt()`는 반환되지 않는다** — 사용자에겐 앱이 그대로 멈춘 것으로 보였다.

### How
- `src/components/FileBrowser.tsx`: 앱 내부 텍스트 입력 모달로 교체 — 자동 포커스 + 기존 이름 전체 선택, **Enter = 확인**, **Esc/배경 클릭 = 취소**.
