# 2026-06-21 작업 로그

## #110 (GitHub) / #29 (GitLab) — 전체화면 TUI에선 →/End 인라인 제안 수락 비활성

### 무엇을 / 왜
- 인라인 제안 수락(→/End, #102)이 vim·Claude Code 같은 전체화면 TUI 안에서도 동작해, →를 누르면 잔여 제안이 수락되고 키가 앱으로 안 갔다.

### 어떻게 (`Terminal.tsx`)
- 전체화면 앱 = **대체 화면 버퍼**(`term.buffer.active.type === "alternate"`).
- onData 줄 추적/제안 계산을 대체 화면이면 건너뜀(그쪽 입력은 셸 명령줄 아님) + lineBuf/제안 비움.
- `onBufferChange`에서 대체 화면 진입 시 잔여 제안 즉시 클리어.
- →/End 핸들러 조건에 `type !== "alternate"` 가드 추가 → 가로채지 않고 앱으로 통과.
- 일반 화면 동작 불변.

### 검증
- `tsc` 통과. 서명 빌드로 vim/Claude Code에서 →·End 네이티브 동작 + 셸 복귀 시 제안 수락 정상 확인 예정.
