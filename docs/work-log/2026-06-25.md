## #119 — macOS: 사설망(192.168.x) SSH 접속 "No route to host" (로컬 네트워크 권한)

### What
- 설치 앱에서 사설망 SSH/SFTP 호스트(192.168.0.27:22 등) 접속 시 `No route to host (os error 65, EHOSTUNREACH)` 실패. 공인 호스트·터미널 `ssh`는 정상.
- 원인: macOS 15+/26 로컬 네트워크 권한. 번들에 `NSLocalNetworkUsageDescription`이 없어 권한 프롬프트도 안 뜨고 시스템 설정 목록 등록도 안 돼 LAN 연결이 조용히 차단됨.

### Why (진단 — 예상 아닌 실측)
- 저장 호스트 데이터 정상(192.168.0.27:22, cuter74, proxy_jump 없음), 라우팅 정상(셸 `nc` 성공).
- `establish_inner`에 임시 raw-TCP 프로브(eprintln) 삽입 → dev 앱(터미널 자식, 로컬 네트워크 권한 상속)에서 `raw TCP connect to 192.168.0.27:22 OK`. 설치 앱만 차단 → macOS 로컬 네트워크 권한 거부로 확정.

### How
- `src-tauri/Info.plist` 신규 생성, `NSLocalNetworkUsageDescription` 선언. Tauri가 macOS/iOS 번들 Info.plist에 자동 머지.
- 검증: `tauri build --bundles app`로 빌드한 `wowTerminal.app/Contents/Info.plist`(v0.19.2)에 키가 들어감을 `PlistBuddy`로 확인.
- 진단용 eprintln은 원복(소스 동작 무변경, plist만 추가).
- 기존 설치 사용자 임시조치: 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → wowTerminal 켜기. (사용자 확인: 권한 켜기 전에도 새 빌드에서 접속됨)

## #120 — 호스트 목록 그룹 접기/펴기 (+ 화살표 크기)

### What
- 데스크탑 호스트 리스트의 그룹 헤더 접기/펴기가 동작 안 하고(▾는 장식), 아이콘이 작아 안 보이던 문제.

### Why
- `GroupSection` 헤더에 onClick 토글도 collapsed 상태도 없었음 — 접기/펴기 기능 자체가 미구현.

### How
- `src/components/HostList.tsx`: 헤더 전체를 토글 `<button>`으로, 접힘 상태를 그룹별(`groupKey`=group id 또는 `__ungrouped__`) localStorage(`wt.hostgroup.collapsed`)에 영속화. 화살표 ▶(접힘)/▼(펼침)로 키움(13px). 접힘 시 호스트 목록 숨김.
- dev 앱 실측 확인(사용자 OK).
